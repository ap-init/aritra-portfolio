# AP Portfolio Website

A responsive portfolio inspired by the supplied screenshots. It uses plain HTML, CSS and JavaScript, so there is no build step or npm dependency.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server, or run any static server:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Before publishing

Edit these placeholders in `index.html`:
- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- X/Twitter URL
- project Code / Live links
- `assets/resume.pdf` with your final resume

## GitHub Pages

1. Create a GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then Save.
6. GitHub will provide your live `github.io` URL.

## Netlify / Vercel

You can also drag the project folder into Netlify or import the GitHub repository into Vercel. No build command is required.

## Design features

- Dark purple/black visual style matching the screenshots
- Responsive mobile navigation
- Dark/light theme toggle
- Smooth scrolling
- Project category filtering
- Contact form using `mailto:`
- Resume download button
- Mobile-friendly layout
